--------------------------------------------------
PHASE STRUCTURE
--------------------------------------------------

Each skill is defined over a continuous phase variable:

- Phase ∈ [0, 1]
- Phase evolves monotonically
- A skill is EITHER cyclic (phase 1 == phase 0, a gait/dance that repeats) OR
  one-shot (distinct start and end poses — a pick-and-place, a vault, a climb).
  Do not force a one-shot skill to be periodic.

Sub-phases begin at motion events (a contact change, a reversal, an apex) and
last as long as their motion takes — never equal fractions by default. Skills
typically evolve limb roles and couple base to limb motion across phase, but a
steady glide or constant-role motion with a single sub-phase is also valid.
